## 2. 三个关键发现（决定了解析器怎么写）

### 发现 1：约一半 PDF 是扫描件，且集中在"低价值"文档

| 类型 | 有文字层 | 扫描件 |
|---|---:|---:|
| 真题 PDF | 少数 | 多数（02326 的 202104/202110/202204/202304，03708 的 201804/202008/202010/202104） |
| 教材/通关宝典/官方笔记 | **绝大多数** | 少数（高数工本、Java 教材、密训资料） |
| 精讲课件 PDF | 几乎没有 | **12 份 × 平均 100 页，全是图片** |

**结论**：精讲课件是"PPT 导出成图片"，OCR 出来排版全乱，性价比极低。**直接跳过**，用同科目的"通关宝典/官方笔记"替代（它们有文字层，内容更浓缩）。

### 发现 2：答案有三种分布，必须做"答案对齐"

| 分布 | 典型文件 | 处理方式 |
|---|---|---|
| **A. 题后紧跟答案** | `03708...201810【答案在题目上】.doc`、`2016年10月Java...真题答案+解析+知识点.docx` | 最容易，直接状态机解析 |
| **B. 答案集中在卷尾** | 文件名带`【答案在试卷后】`的 03708 卷 | 先切"题目区/答案区"，再按题号把 `1.A 2.B` 配对回去 |
| **C. 答案在单独文件** | `02326-202410-题目.docx` + `02326-202410-参考答案.pdf` | 文件名配对 + 题号对齐，人工确认一次 |

已经实测过的理想样例（03708 201810）：

```
1、鸦片战争前中国封建社会的主要矛盾是()
A.地主阶段和农民阶级的矛盾
B.帝国主义和中华名族的矛盾
C.资产阶级和工人阶级的矛盾
D.封建主义和资本主义的矛盾
【答案】A
【解析】1840年鸦片战争之前……
【考点】鸦片战争前的中国          ← 这是白送的知识点标签
```

> `【考点】` 字段是宝藏：03708 的真题里有 78 处。它天然就是"题目 → 知识点"的映射，直接拿来建知识点体系，不用猜。

### 发现 3：格式噪声大，必须"先归一化再切题"

实际遇到的脏数据：

| 噪声 | 例子 | 处理 |
|---|---|---|
| 分隔符混用 | `1·` `1、` `1.` `A．` `A、` `A.` `A·` | 统一正则 `[.、．·，,]` |
| 一行多个选项 | `A·网络化    B．智能化    C．实时化   D．自动化` | 按 `A-F` 标记二次切分 |
| 题号丢失 | 第 8 题前面没有 `8、` | 用"上一题号 +1"补齐，标记为待校对 |
| 页眉页脚 | `操作系统试题 第 1 页 ( 共 6 页 )` | 正则删除 |
| 广告行 | `后续更新试题或答案请加微信 18153984875` | 关键词黑名单 |
| 全半角括号 | `（  ）` `(  A  )` | 括号内答案提取（讲义里的题常见） |
| 公式乱码 | `2¹²` `2²0` | 保留原样 + 标记，建议图片化 |

### 学习模式（新增，不只是刷题）

1. **卡片流**：一章一组，左滑"会"、右滑"不会"，自动进入间隔重复队列
2. **学完即测**：看完知识点立刻推 3 道关联真题，答对才算掌握
3. **知识点反查**：刷题答错 → 弹出关联知识点卡片 → "原来考的是这个"
4. **薄弱知识点**：按章节统计正确率，低于 60% 的自动排到首页

> 这样"学知识点"和"刷题"不是两个割裂的功能，而是同一个记忆闭环。

## 6. 按题型刷题（你提的第二个需求）

现有的题目类型分布（按自考卷面）：

| 科目 | 题型结构 | 每卷题数 |
|---|---|---:|
| 03708 中国近现代史纲要 | 单选 25×2 分 + 简答 5×6 分 + 论述 3 选 2×10 分 | 33 |
| 02326 操作系统 | 单选 20×1 + 填空 10×2 + 简答 5×4 + 综合 2×15 | ~37 |
| 04747 Java（一） | 单选 10×1 + 填空 10×2 + 简答/程序 若干 | ~30 |

组卷器要支持这些维度任意组合：

```
学科：操作系统
题型：☑ 单选  ☑ 多选  ☐ 填空  ☑ 简答  ☐ 综合
范围：☑ 全部章节  ☐ 指定章节
年份：2015 ~ 2024
其他：☑ 只做错过的  ☐ 只做没做过的  ☑ 打乱顺序  ☐ 打乱选项
数量：30
                          [ 开始练习 ]
```

三个细节：

- **打乱选项**要同步重映射答案（`A→C`），否则对不上——这是很多刷题工具做错的地方
- **按题型专项**时，主观题默认走"自评"模式，不强行判分
- **真题整卷**和**拆散重练**是两种模式，共用同一批题，通过 `paper` 表保留原始卷面结构
